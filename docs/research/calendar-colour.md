# 日期面板的颜色从哪来 —— 以及汉化盘到底动了什么

结论先行：**日历里「周日／节假日粉红、周六蓝」的判定链（画笔选择码、日号池、月长表、节假日表）
汉化盘与母盘逐字节相同——丢的是画笔自己那份 RGB，它住在字库带最后 16 个格子里，
被终局的整带回填涂掉了（见 §四）。** 本文件记录三件事：
(1) 这条链路的地址与语义；(2) 一份「本盘究竟改了哪些字节」的**穷举**，
用来回答「全系统排查类似问题」——它把「没动引擎」从抽查变成枚举；(3) 修复与拨号簿实测。

## 一、画笔是怎么选出来的

`$98:DA12`（file `0x0C5A12`–`0x0C5A23`）：

```
A5 0E      LDA $0E          ; $0E = 当天类型
D0 05      BNE +5
A0 00 38   LDY #$3800       ; 类型 0（周日/节假日）-> 笔 $38 = 粉红
80 08      BRA
C9 06 00   CMP #$0006
D0 03      BNE
A0 00 34   LDY #$3400       ; 类型 6（周六）-> 笔 $34 = 蓝
           A0 00 30         ; 其余 -> 笔 $30 = 黑
8C 2A 0A   STY $0A2A        ; 写进画笔寄存器
```

* `$38-$3F` 是**画笔族**控制码：`$80:CD67`（file `0x04D67`）里 `SEC : SBC #$38 : JSL $CD77`，
  8 个变体同一个操作（见 `control-codes.md`）。`$30-$37 xx` 是带操作数的另一族（`$80:CD8C`）。
* 字形：日号 = `0x15B + LDA $81:F3FA,X`，即 `$81:F3FA`（file `0x00F3FA`，内容是 12 个月天数
  `1F 1C 1F 1E …`）当偏移，落到半宽补充带 `$0153-$01C4` 的那批数字格上。
* 消费 `0A2A` 的处理与两处 `JSL $80CD77` 也都在同一带代码里。

## 二、bank `$83` 里日历周边的真实布局

| file | 内容 | 本盘是否改写 |
|---|---|---|
| `0x1834B`–`0x183A0` | 九个两字能力标签（体力/文科/理科/艺术/运动/杂学/容姿/毅力/压力） | 是（`0x1835C`–`0x1839E`） |
| `0x183A1`–`0x183DE` | **日号池** `F1 5B … F1 79`，31 条 ×2 B，**不带任何画笔码** | **否，逐字节相同** |
| `0x183DF`–`0x18401` | 面板头记录 `34 06 35 00 36 01 3B 04 21 F0 6D F0 75 F0 75 …`（`１９９` 在这里） | 否 |
| `0x18402`–`0x1840D` | 12 个月记录的 stride-7 偏移表 | 否 |
| `0x1840E`–`0x18461` | 12 条月名记录（`Ｊａｎ`… → `一月 `…），每条 7 B、`$0A` 收尾 | **是**（原地等长重写） |
| `0x18462`–`0x18470` | 第二个 `$01 32` 跳转 + 12 条月数字记录的 stride-4 偏移表 | 否 |
| `0x18471`+ | 月数字记录，**首字节就是画笔码**（`3D F0 6D 0D 0A`） | 否 |

要点：**日号的颜色不在日号池里**，池子只有字形码；颜色由上面那段 `$0E`→`$0A2A` 的代码在画每个
格子时现选。所以只要「日号池 + 画笔选择码 + 月长表 + 半宽数字带」四样不变，颜色就不可能变。

## 三、本盘改了哪些字节（穷举）

`tools/` 里的一次性比对（合并相邻差异后 148 段 / 451,539 B）按 bank 归类只有这几族：

| bank | file 区间 | 归属 |
|---|---|---|
| `$80` | `0x0048F1`（2 B） | `NAME_IMM` 默认名 `鈴→铃` 的字形码立即数 |
| `$83` | `0x18012`–`0x1FA37` | 码表 + `SYSTEM_TEXT` + `UI_LINE_ROWS` 池行 |
| `$85` | `0x028B54`（2 B） | 同一处 `NAME_IMM`（`LDA #$13FD`→`LDA #$A8FB`） |
| `$86/$98/$9A/$B6` | `0x34F87`、`0xC6EB0`、`0xD6F9A`、`0x1B6073` | Z1–Z4 未注册剧情流（`build_prologue.py` 的 known 表） |
| `$B9`–`$CF` | `0x1C8006`–`0x23F669` | 142 个 TEXT_PTRS 块正文 |
| `$FC`–`$FF` | `0x3E606D`–`0x3FFFF8` | 字库（含整带回填） |

**除那两处 2 B 的默认名立即数之外，`$83` 以上没有任何一段落在引擎代码里**；`0x18000` 以下
（代码、调色板、表）总共只有 2 个字节不同。日历相关的四段代码/表（`0x0C5A12`、`0x04D67`、
`0x00F3FA`、`0x183A1`–`0x1840D`）与半宽数字带 `0x153`–`0x1C4` 的字模记录，全部零差异。

## 四、真正的漏洞在字库带的尾巴上（2026-09-24 定位并修复）

静态那三样（画笔选择码、日号池、月长表）确实零差异，**但画笔的 RGB 不在这三样里**。
`$80:CD8C`（`$30-$37 xx` 那一族）不是「选一个固定颜色」，它是**装色调色板**：

```
80CD8C: A7 B4    LDA [$B4]        ; 取到 $3x 与它的操作数
80CD92: 38 E9 30 00  SEC : SBC #$0030
80CD99: 0A 0A 0A 1A 1A  A8        ; Y = (code-$30)*8 + 2
80CD9C: A9 00 2C 85 00  A9 7E 00 85 02   ; 目标 = $7E:2C00（WRAM 画笔表）
80CDAE: BF 3A FE FF  LDA $FFFE3A,X       ; ← 颜色三元组来自 ROM
80CDB2: 97 00        STA [$00],Y
80CDB7: BF 38 FE FF  LDA $FFFE38,X
80CDBB: 97 00        STA [$00],Y
```

`X = 操作数 × 4`，所以 **`$FF:FE38` 是一张 4 字节表项的调色板**。
按 `$83`/`$81` 那套「bank-$80 起算 32 KB」的映射，`$FF:FE38` = file **`0x3FFE38`**
= `glyph_offset(0x0DA6)` —— **它正好住在字库第 3 页最后 16 个格子里**。

终局 #43 的「汉字带整带回填」写的是 `range(JIS_KANJI, MAX_INDEX)`，
`MAX_INDEX = 0xDB6`，于是把 **0xDA6–0xDB5 这 16 格连调色板一起涂成了文泉驿点阵**：
粉红那格的 RGB 变成 `00 00`（黑），周六那格变成某个字模的行（绿）。
**周日／节假日的判定、日号池、画笔选择码全都是对的，只有它们要用的那个颜色被擦掉了。**

旁证：母盘上 `0x3FFE38`–`0x3FFEE4` 之后才是 `FF` 填充（`0x3FFEE4` 之后一路到 `0x3FFFF8` 全 `FF`），
即表项 0–42；而 `tools/idx_census.py` 数下来 0x49B 以上有 1,351 个「没有正文引用」的格子——
这 16 格就在那片空地里，**日文自己也不画它们**，所以它们才被拿来放调色板。

修法：`tmtext.GLYPH_WRITABLE_MAX = 0x0DA6`，构建里三处上界（回填循环、`allocate()` 的槽位池、
`stock_binding()` 的 A 档判定）都改用它。修完 `0x3FFE38` 以上与母盘**逐字节相同**，
`font: … 0 unclaimed slot(s) changed` 不破。

> 教训：**「字库带全是中文的地盘」这句话有一个尾巴上的例外。** 槽位池的上界不是 `MAX_INDEX`，
> 而是第一处被引擎当成别的什么用的地址。同类排查要问的是「我涂到的每一个区间，
> 除了当字模，还有没有别的代码在读它」——本次扫 `$80-$83` 全部 `$FF:FFExxx` 引用，
> 只有 `LDA $FFFE38,X` / `LDA $FFFE3A,X` 两条，都在这个装色处理器里，所以受影响的只有这一处。

## 五、拨号簿（通讯录）：判定口径与实测

判定口径：**界面是否前进只能看截图，不要拿画面统计量（白度、高亮条变化之类）当 transition
的判据**——母盘与中文盘在拨号簿上的行为一模一样，都是能走通的，按一次 A 没见画面大变就下
「没反应」的结论会误判（以下实测跑在用户存档 96/4/14 上）。

* 指针格点阵是 **x ≡ 41 (mod 4)、y 为偶数**（左右 4 px、上下 2 px）。
* 拨号簿是**三列**：左列 好雄(y≈34)／诗织(y≈50)，右列 伊集院丽(y≈74–86, x≈325–349)／取消(y≈122, x≈325)。
* **第一次按 A 只是「按住」条目**（蓝色高亮条、消息框念出名字，画面白度只动 175–531，前进箭头还会消失），
  **第二次按 A 才真正拨号**。
* **打电话不会翻页**：白页一直留在屏幕上，对话走下面的消息框，所以「画面变暗＝离开通讯录」
  这个检测在通话期间永远不成立，别拿它判断通话结束。
* 白度基线：房间 5,200–5,900 / 通讯录 53,000–54,100 / **日期面板 67,110**（比通讯录更白，
  用 `<50000` 找面板必然找不到）。
* 房间图标里 **(41,104) 与 (85,104) 都不会推进日期**；日期靠「消耗行动力」烧掉，
  点 (41,56) 读书 6–8 次就翻周。
