## 版本适用性

| 版本 | CRC32 | 备注 |
|---|---|---|
| Ver 1.0 | `6A3CCEB1` | |
| Ver 1.1 | `AE9F3602` | **即本项目母盘**：`rom_original_japanese.sfc`（无头文件整体 CRC32 实测 `AE9F3602`，2026-09-22 核验），以下代码直接适用 |

所有地址均为 **WRAM（$7E:xxxx，RAM 映射）** 地址，改的是运行内存而非 ROM 镜像，
因此与汉化补丁互不冲突；中文盘同样有效（前提是不动这些运行时字节）。

## 一、能力值代码

每两个相邻地址组成一个小端 16 位值（低字节在前），取值范围 `0x0000–0x03E7`（0–999）。
`xx` 为要写入的值。

| 代码 | 内容 |
|---|---|
| `7E0B00xx` + `7E0B01xx` | 体力（原文「体調」） |
| `7E0B02xx` + `7E0B03xx` | 文科 |
| `7E0B04xx` + `7E0B05xx` | 理科 |
| `7E0B06xx` + `7E0B07xx` | 艺术 |
| `7E0B08xx` + `7E0B09xx` | 运动 |
| `7E0B0Axx` + `7E0B0Bxx` | 杂学 |
| `7E0B0Cxx` + `7E0B0Dxx` | 容姿 |
| `7E0B0Exx` + `7E0B0Fxx` | 勇气（原文「根性」） |
| `7E0B10xx` + `7E0B11xx` | 压力 |

注：能力项顺序与本项目面板标签实测一致（体力/文科/理科/艺术/运动/杂学/容姿/勇气/压力，
见 `translations/term_glossary.tsv` 口径），可用于交叉验证面板显示。

## 对本项目的潜在用处

- **验收加速器**：`7E0C58xx`（约会次数）＋能力值代码可直接把游戏推到期末评价/结局链，
  不必真肝三学年，配合 walk 脚本可缩短模拟器层的验证路径。
- **显示层交叉证据**：能力名顺序、状态文案（受伤/神经症/生病）都是面板与事件文案的
  日→中对照锚点；地址 $0B00 起的「9 项×2 字节＋状态」布局可反向印证面板 RAM 结构
  （含第 9 项压力用半宽格拼接的机制）。
- 这些是运行时 WRAM 字节，**不与 ROM 补丁冲突**，也不受码表/字库重排影响。
