# 通读回报的「只能改词典体」清单（批次 AM 的欠账，待逐族裁决）

2026-09-26 从 31 路通读 notes 的 ② 段原样收录：**44 条请求，来自 7 路**（w00/w10/w13/w21/w32/w33/w36），
其余 24 路回报「本块没有只能改词典体的事」。`n` 是该块 `blockN_work.tsv` 里 0-based 的步号。

这一族的性质：句子住在共享词典（`$A0-$EF` 短语宏 / `$E8xx` 子句）里，框只花 1~3 字节调用它，
所以**框内改不动**——要么改宏体正文（＝同时改全部调用点），要么不动。裁决每条之前必须按
`AGENTS.md` §五 扫一遍调用点：带前后缀的调用（「是让人〔犯困的季节〕呢」那种）一改就不再折叠，
框凭空多出整段字面字节（批次 AG 的 b47 就是这么炸出来的）。`span / used` 是该宏体自己那段的预算，
正文只能写进那一段，不能搬位置。
